# PrusaLink on Proxmox (LXC)

Run on the **Proxmox host** as **root** (next free CT/VM ID ≥100; optional interactive USB). Pin an ID, e.g. `CTID=101` in the same environment before `bash -c`.

```bash
bash -c "$(curl -fsSL https://raw.githubusercontent.com/SchmidtPhilipp/05_prusa/main/prusalink_proxmox_lxc_install.sh)"
```
